# Portafolio · Pamela Rodríguez

Portafolio personal de Daira Pamela Rodríguez Gómez, estudiante de Ingeniería de Software en la Universidad de Colima. Muestra mis proyectos, certificaciones y habilidades para puestos fullstack, data y QA.

## Características

- Selector de **enfoque** (Todo / Fullstack / Data / QA) que resalta los proyectos, habilidades y certificaciones relevantes para cada perfil.
- Español e inglés.
- Modo claro y oscuro.
- Galería de imágenes y videos por proyecto.

## Tecnologías

React 19, TypeScript y Vite.

## Correr en local

```bash
npm install
npm run dev
```

## Editar el contenido

Todos los textos, proyectos, habilidades y certificaciones están en [`src/data/content.ts`](src/data/content.ts). Las imágenes y videos van en `public/media/`.
